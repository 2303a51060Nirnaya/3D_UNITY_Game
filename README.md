# 🪙 Coin Collector – 3D Unity Game

## 📌 About the Game

Coin Collector is a 3D game developed using Unity. The main objective is to control the player, explore the game environment, collect coins, and achieve the highest possible score.

The game provides an interactive 3D environment with player movement and coin collection mechanics.

## 🎮 Game Features

* 3D game environment.
* Player movement and controls.
* Coin collection system.
* Score tracking.
* Interactive gameplay.
* Unity-based game development using C#.

## 🛠️ Technologies Used

* Unity 3D
* C#
* Visual Studio
* Git and GitHub
* Git LFS

## 🎯 How to Play

1. Open the game project in Unity Hub.
2. Open the `CoinCollector.unity` scene.
3. Press the Play button.
4. Use the player controls to move around the environment.
5. Collect coins to increase your score.

## 💻 How to Run the Project

1. Download or clone this repository.
2. Extract the project if downloaded as ZIP.
3. Open Unity Hub.
4. Select Add Project from Disk.
5. Choose the `CoinCollector_Mixed_Road_Grass_Park` folder.
6. Open the project in Unity.
7. Open the CoinCollector scene.
8. Click Play to run the game.
